# JustTalk Explainer Storyboard

Статичная страница-раскадровка для эксплейнера JustTalk Interview Sprint (~45 сек, 16:9). Без сборки и зависимостей: открыть `index.html` в браузере или поднять любой статический сервер (`npx serve .`).

## Структура

- `index.html` — каркас: шапка с логотипом и блоками референсов, пустой `<main id="panels">`.
- `styles.css` — все стили. Цвета только через токены в `:root`; тёмная тема переопределяет токены в двух блоках (`prefers-color-scheme` и `[data-theme="dark"]`).
- `data.js` — весь контент:
  - `REFS` — референсы по ключу сцены;
  - `COACH_MEDIA` — путь к фото или видео коуча для плашки «Реальный коуч» (пусто — условный силуэт), `COACH_MEDIA_NOTE` — подпись в углу плашки; сейчас стоит стоковая заглушка `refs/coach-placeholder.mp4` (Pexels), её надо заменить на настоящего коуча;
  - `VARIANTS` — варианты закадра (`a`, `b`, `c`, `d`), у каждого `title`, `idea` и массив `scenes`;
  - `COMMON` — HTML общего раздела (идёт первым).
  - `BOARDS_INTRO` — текст и аудиопримеры под заголовком «Условные варианты раскадровок», перед вариантом A;
  - `OUTRO` — HTML блока после всех вариантов (необязательная вставка).
- `frames.js` — условные кадры раскадровки: абстрактные SVG-наброски 320×180 в объекте `FRAMES` по ключу `<вариант>-<номер сцены>`, собраны из общих примитивов (человечек, эквалайзер, окно звонка, отчёт, плитки и т. д.). Цвета только через классы `f-*`, `s-*`, `t-*` из `styles.css`.
- `cal3d.js` и `calbook3d.js` — 3D-примеры к «Календарь → плитки» на three.js r128: изометрические плитки (`mountCal3D`) и перекидной календарь спринта (`mountCalBook3D`). Библиотека грузится с cdnjs из `app.js` только когда плашка появляется на экране; цвета берутся из CSS-токенов.
- `app.js` — рендер разделов и сцен одной страницей (общий, затем варианты по порядку `order`), анимация логотипа.
- `refs/` — картинки-референсы.
- `audio/` — примеры начитки с музыкой (mp3).

## Сцена

```js
{ t: "0:14–0:20",            // таймкод
  name: "День 0 · мок и отчёт", // короткое название
  vo: "Start with a live mock interview…", // реплика закадра (EN)
  ru: "Начните с живого пробного интервью…", // перевод
  os: "Live mock interview",  // текст на экране ('' если нет)
  vis: "Что происходит в кадре" }
```

## Как добавить референс

Ключ = `<вариант>-<номер сцены>` (номер с 1, как на странице).

```js
const REFS = {
  "a-5": [{ src: "refs/a5-1.jpg", caption: "Окно звонка + отчёт" }],
};
```

Можно несколько картинок на сцену. Блок «Референс» появляется в карточке сцены, только если для неё есть картинки.

## Как добавить вариант

1. Добавить объект в `VARIANTS` (например `e`).
2. Добавить `'e'` в массив `order` в `app.js`.

## Правила по содержанию

- Закадр на английском, перевод на русском рядом.
- Коуча в закадре по имени не называем.
- Не обещаем гарантию и проценты улучшения; цифры только с лендинга interview.justtalk.ai (28 дней, 3 мока, 7 сессий с коучем, 22 дня практики, 3 звонка в день, 3 месяца практики, аудит $99).
- Каждый вариант заканчивается репликой «Just talk.»
- Числа в тексте для ElevenLabs пишем словами, «A.I.» с точками.
