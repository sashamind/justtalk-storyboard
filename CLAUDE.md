# JustTalk Explainer Storyboard

Статичная страница-раскадровка для эксплейнера JustTalk Interview Sprint (~45 сек, 16:9). Без сборки и зависимостей: открыть `index.html` в браузере или поднять любой статический сервер (`npx serve .`).

## Структура

- `index.html` — каркас: шапка, вкладки, пустой `<main id="panels">`.
- `styles.css` — все стили. Цвета только через токены в `:root`; тёмная тема переопределяет токены в двух блоках (`prefers-color-scheme` и `[data-theme="dark"]`).
- `data.js` — весь контент:
  - `REFS` — референсы по ключу сцены;
  - `VARIANTS` — варианты закадра (`a`, `b`, `c`, `d`), у каждого `title`, `idea` и массив `scenes`;
  - `COMMON` — HTML вкладки «Общее».
- `app.js` — рендер вкладок и сцен, переключение перевода, копирование текста закадра.
- `refs/` — картинки-референсы.

## Сцена

```js
{ t: "0:14–0:20",            // таймкод
  name: "День 0 · мок и отчёт", // короткое название
  vo: "Start with a live mock interview…", // реплика закадра (EN)
  ru: "Начните с живого пробного интервью…", // перевод
  os: "Live mock interview",  // текст на экране ('' если нет)
  vis: "Что происходит в кадре" }
```

## Как добавить референс

Ключ = `<вариант>-<номер сцены>` (номер с 1, как на странице), для общей вкладки `common-1`.

```js
const REFS = {
  "a-5": [{ src: "refs/a5-1.jpg", caption: "Окно звонка + отчёт" }],
};
```

Можно несколько картинок на сцену. Пустая ячейка показывает подсказку с ключом.

## Как добавить вариант

1. Добавить объект в `VARIANTS` (например `e`).
2. Добавить кнопку вкладки в `index.html`: `<button role="tab" id="tab-e" data-panel="e">E · …</button>`.
3. Добавить `'e'` в массив `order` в `app.js`.

## Правила по содержанию

- Закадр на английском, перевод на русском рядом.
- Коуча в закадре по имени не называем.
- Не обещаем гарантию и проценты улучшения; цифры только с лендинга interview.justtalk.ai (28 дней, 3 мока, 7 сессий с коучем, 22 дня практики, 3 звонка в день, 3 месяца практики, аудит $99).
- Каждый вариант заканчивается репликой «Just talk.»
- Числа в тексте для ElevenLabs пишем словами, «A.I.» с точками.
